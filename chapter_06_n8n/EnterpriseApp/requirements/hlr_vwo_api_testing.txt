Objective

In app.bw.com, we see there are two types of APIs which are present. First one is the login API. The second one is called the registration API or signup API.
In the login API, the user will enter the email and password, which is a working password that they have. If it is valid, we will be able to log into the dashboard. If it is invalid, then we will get an error.
